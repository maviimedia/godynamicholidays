# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.

# GoDynamicHolidays

**GoDynamicHolidays** is a full-stack travel agency platform designed to streamline travel package management and lead generation. It features a responsive, customer-facing booking website and a secure, real-time Content Management System (CMS) for administrators.

## Tech Stack
*   **Frontend:** React.js, Vite, Tailwind CSS v4
*   **Backend, Database & Storage:** Convex
*   **Routing:** React Router v6
*   **Icons & Typography:** Remixicons, FontShare (DM Sans)

## Key Features

*   **Real-Time Admin CMS:** A password-protected dashboard to manage the entire platform.
*   **Package Management (CRUD):** Create, edit, and delete travel itineraries. Includes dynamic routing destinations, pricing logic, and highlights.
*   **Cloud Image Storage:** Direct image uploads to Convex storage for main package banners and gallery images.
*   **Lead Management:** Real-time synchronization of customer inquiries from the website directly to the admin dashboard with status tracking (New, Contacted, Converted).
*   **Dynamic Client Routing:** Auto-generated destination pages based on active database inventory.
*   **Search Functionality:** Live filtering of travel packages on both the client-facing navigation bar and the admin dashboard.
